## สรุปโครงงาน

**Unit Hunter** คือเกมเว็บเพื่อการเรียนรู้ ที่นำการฝึกแปลงหน่วย SI มาใส่ไว้ในเกมต่อสู้ ผู้เล่นตอบโจทย์เพื่อโจมตีหรือป้องกันศัตรู จึงได้ฝึกคำนวณระหว่างเล่นเกม

อธิบายสั้น ๆ ได้ว่า:

> “เกมเว็บแนวต่อสู้แบบผลัดตา ที่ให้ผู้เล่นฝึกแปลงหน่วยผ่านโจทย์ความรู้ โดยคำตอบมีผลต่อการต่อสู้และการวางแผนเล่น”

## ผู้ใช้และเนื้อหาที่ฝึก

กลุ่มผู้ใช้ที่ระบุไว้ในเอกสารออกแบบคือผู้เรียนระดับมัธยมต้น เนื้อหาหลักคือการแปลงหน่วย SI โดยข้อมูลในโค้ดครอบคลุม 7 หมวด ได้แก่ ความยาว มวล เวลา กระแสไฟฟ้า อุณหภูมิ ปริมาณสาร และความเข้มการส่องสว่าง

มีข้อแตกต่างที่ควรเขียนให้ตรงกับตัวเกม: **โหมดฝึกทั่วไป** เลือกฝึกได้หลายหมวด ส่วน **Expedition** และภารกิจรายวันให้เลือกเฉพาะความยาว มวล หรือเวลา

## วิธีเล่นโดยย่อ

1. เลือกโหมดและหัวข้อที่ต้องการฝึก
2. เข้าต่อสู้และเลือกสกิล
3. ตอบโจทย์แปลงหน่วยเพื่อให้การโจมตีหรือการป้องกันมีผล
4. เมื่อตอบถูก จะมีช่วงกดจับจังหวะ (QTE) ซึ่งกำหนดระดับผลลัพธ์ Perfect, Good หรือ Bad
5. เดินหน้าไปตามแผนที่ เลือกห้องต่อสู้หรือห้องประเภทอื่น เก็บรางวัลและปรับสกิล
6. ดูผลการเล่นและประวัติการฝึก

โหมด Expedition มีแผนที่แตกแขนง ห้องเหตุการณ์ ร้านค้า สมบัติ จุดพัก และบอส การตอบผิดมีคำอธิบาย และระบบสามารถนำแนวคิดที่เคยตอบผิดกลับมาให้ฝึกอีกครั้ง

## ระบบที่พบในงาน

โค้ดแบ่งส่วนตามหน้าที่ เช่น ระบบสร้างโจทย์และแปลงหน่วย ระบบต่อสู้และศัตรู ระบบสกิลและรางวัล ระบบแผนที่และการเดินทาง ระบบบันทึกผล และส่วนติดต่อผู้เล่น ตัวเกมทำด้วย **HTML, CSS และ JavaScript แบบ ES Modules** และเปิดทดลองผ่านเว็บเซิร์ฟเวอร์ภายในเครื่องด้วย Node.js

มีระบบสร้างโจทย์ด้วย AI เป็นตัวเลือก โดยผู้ใช้ต้องตั้งค่า API key เอง ส่วนข้อมูลการเล่นและอันดับที่พบในโค้ดเป็นการเก็บไว้ในเบราว์เซอร์/เครื่องผู้ใช้ เอกสารระบุว่ายังไม่มีระบบอันดับออนไลน์ที่ตรวจสอบผลผ่านเซิร์ฟเวอร์จริง

## แบบร่างข้อเสนอโครงงาน (Proposal)

> ส่วนนี้เป็นโครงสำหรับร่างข้อเสนอก่อนทำหรือก่อนนำเสนอโครงงาน ไม่ใช่รายงานผลการดำเนินงานฉบับสมบูรณ์ ให้แทนที่ข้อความในวงเล็บเหลี่ยมด้วยข้อมูลจริง และตัดหัวข้อที่แบบฟอร์มของอาจารย์ไม่ได้กำหนด รูปแบบและลำดับหัวข้ออาจต่างกันตามสถานศึกษา จึงควรตรวจแบบฟอร์ม/เกณฑ์ของรายวิชาก่อนส่ง

### 1. ชื่อโครงงาน

**ชื่อภาษาไทย:** [ระบุชื่อที่สื่อว่าเป็นเกมฝึกแปลงหน่วย SI]<br>
**ชื่อภาษาอังกฤษ:** [ระบุชื่อภาษาอังกฤษ]

### 2. ที่มาและความสำคัญ

[อธิบายบริบทการเรียนเรื่องหน่วย SI และการแปลงหน่วย ระบุปัญหาหรือความต้องการที่พบ พร้อมหลักฐานหรือแหล่งอ้างอิงที่ตรวจสอบได้ จากนั้นอธิบายว่าเหตุใดเกมเว็บที่ผสานโจทย์เข้ากับการต่อสู้จึงอาจช่วยให้การฝึกน่าสนใจหรือเข้าถึงง่ายขึ้น อย่าเขียนผลว่าเกมช่วยเพิ่มผลสัมฤทธิ์แล้ว หากยังไม่ได้ทดลอง]

### 3. ปัญหา/คำถามของโครงงาน

[ระบุปัญหาที่โครงงานต้องการแก้ให้ชัด เช่น ผู้เรียนต้องการวิธีฝึกแปลงหน่วย SI ที่มีปฏิสัมพันธ์และได้รับผลตอบกลับระหว่างทำโจทย์ ควรอธิบายว่าทราบปัญหานี้จากอะไร]

### 4. วัตถุประสงค์

1. เพื่อพัฒนาเกมเว็บสำหรับฝึกการแปลงหน่วย SI โดยใช้โจทย์เป็นส่วนหนึ่งของระบบต่อสู้
2. เพื่อ [ระบุสิ่งที่จะประเมิน เช่น ความถูกต้องและการทำงานของระบบ หรือความคิดเห็น/ประสบการณ์ของผู้ทดลองใช้]

### 5. ขอบเขตของโครงงาน

- **กลุ่มเป้าหมาย/ผู้ทดลองใช้:** [ระบุระดับชั้น จำนวนโดยประมาณ และวิธีคัดเลือก — ยืนยันกับอาจารย์ก่อน]
- **เนื้อหา:** ระบบในโค้ดมีโจทย์ 7 หมวด ได้แก่ ความยาว มวล เวลา กระแสไฟฟ้า อุณหภูมิ ปริมาณสาร และความเข้มการส่องสว่าง แต่ Expedition และภารกิจรายวันรองรับเฉพาะความยาว มวล และเวลา ให้กำหนดว่าจะศึกษา/นำเสนอส่วนใด
- **แพลตฟอร์มและขอบเขตระบบ:** เกมเว็บ HTML, CSS และ JavaScript แบบ ES Modules เล่นผ่านเว็บเซิร์ฟเวอร์ภายในเครื่องตามสภาพโครงการปัจจุบัน
- **ฟังก์ชันหลัก:** [เลือกฟังก์ชันที่จะอยู่ในขอบเขต เช่น โหมดฝึก, การต่อสู้, โจทย์และคำอธิบาย, QTE, Expedition, การบันทึกผล]
- **สิ่งที่ไม่ครอบคลุม/ข้อจำกัด:** ข้อมูลการเล่นและอันดับที่พบในโค้ดเก็บในเบราว์เซอร์/เครื่องผู้ใช้ และยังไม่มีระบบอันดับออนไลน์ที่ตรวจสอบผลผ่านเซิร์ฟเวอร์จริง; ระบบสร้างโจทย์ด้วย AI เป็นตัวเลือกและต้องใช้ API key ของผู้ใช้

### 6. แนวคิดและทฤษฎีที่เกี่ยวข้อง (เบื้องต้น)

[ค้นและสรุปแหล่งข้อมูลที่น่าเชื่อถือในหัวข้อต่อไปนี้ โดยเชื่อมโยงกับการออกแบบจริง ไม่ใช่เพียงรวบรวมนิยาม]

- ระบบหน่วย SI และหลักการแปลงหน่วยที่เกมนำมาใช้
- เกมเพื่อการเรียนรู้/การให้ผลตอบกลับในการฝึก
- แนวคิดเกมต่อสู้แบบผลัดตาและ Roguelike เฉพาะส่วนที่เกี่ยวข้องกับกลไกของเกม
- เทคโนโลยีเว็บที่ใช้พัฒนา

### 7. วิธีดำเนินงาน

1. ศึกษาเนื้อหาเรื่องหน่วย SI และรวบรวมข้อกำหนดของผู้ใช้/รายวิชา
2. วิเคราะห์และออกแบบโจทย์ กติกาเกม หน้าจอ และข้อมูลที่ต้องบันทึก
3. พัฒนาและปรับปรุงเกมเว็บตามขอบเขตที่กำหนด
4. ตรวจสอบความถูกต้องของโจทย์ การแปลงหน่วย และการทำงานของฟังก์ชัน
5. [ระบุแผนทดลองใช้/ประเมินผล วิธีเก็บข้อมูล เครื่องมือ และผู้เข้าร่วม หากมี]
6. วิเคราะห์ผลเทียบกับวัตถุประสงค์ และสรุปข้อจำกัด/แนวทางพัฒนาต่อ

### 8. การประเมินผล

[ระบุว่าจะรู้ได้อย่างไรว่าบรรลุวัตถุประสงค์ เช่น กรณีทดสอบความถูกต้องของการคำนวณและฟังก์ชัน แบบประเมินความพึงพอใจ หรือแบบทดสอบก่อน–หลัง หากใช้ผู้เข้าร่วม ให้ระบุจำนวน วิธีดำเนินการ วิธีวิเคราะห์ และการขอความยินยอมตามข้อกำหนดของสถานศึกษา อย่าอ้างประสิทธิผลทางการเรียนหากไม่มีการออกแบบประเมินรองรับ]

### 10. เครื่องมือ/ทรัพยากร

[ระบุอุปกรณ์ ซอฟต์แวร์ ผู้ให้คำปรึกษา ค่าใช้จ่ายหรือทรัพยากรที่ต้องใช้ให้ตรงกับแผนจริง เช่น คอมพิวเตอร์ เว็บเบราว์เซอร์ Node.js และเครื่องมือพัฒนาเว็บ]

### 11. ผลที่คาดว่าจะได้รับ

1. ได้เกมเว็บต้นแบบสำหรับฝึกแปลงหน่วย SI ตามขอบเขตที่กำหนด
2. ผู้ใช้มีสื่อสำหรับฝึกทำโจทย์พร้อมผลตอบกลับระหว่างเล่น [ปรับถ้อยคำตามสิ่งที่ประเมินได้]
3. ได้ข้อมูลจากการตรวจสอบ/ทดลองใช้เพื่อใช้ปรับปรุงเกม [หากมีแผนเก็บข้อมูล]

### 12. เอกสารอ้างอิง

[ใส่รายการอ้างอิงทุกแหล่งที่นำมาใช้ ทั้งในที่มาและความสำคัญ ทฤษฎี และวิธีประเมิน โดยใช้รูปแบบอ้างอิงที่สถานศึกษากำหนด]

### ประเด็นที่ต้องยืนยันก่อนส่ง

- รูปแบบ proposal ความยาว และรูปแบบการอ้างอิงตามข้อกำหนดรายวิชา/อาจารย์
- กลุ่มเป้าหมายและหมวดเนื้อหาที่จะนำเสนอ เพราะโหมดฝึกทั่วไปกับ Expedition รองรับเนื้อหาไม่เท่ากัน
- จะประเมินเพียงการทำงาน/ความพึงพอใจ หรือศึกษาผลการเรียนรู้ด้วย และมีเวลา/การอนุญาตเก็บข้อมูลเพียงพอหรือไม่
