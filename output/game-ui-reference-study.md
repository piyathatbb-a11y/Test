วันที่ตรวจสอบ: 23 ตุลาคม 2026

เป้าหมาย: ทำให้ผู้เรียนเข้าสู่เกมแบบ `หน้าเปิดเกม → เริ่มเล่น → เลือกวิชา → กางแผนที่ → เลือกจุดเริ่มต้น` ได้ง่าย โดยคงการต่อสู้แบบผลัดตาและไม่มีระบบการ์ด

## ข้อเสนอที่นำไปทำได้ทันที

1. **หน้าเปิดเกมมีปุ่มหลักเดียว: “เริ่มผจญภัย”** ใช้ชื่อเกม ภาพโลก และคำโปรยสั้นหนึ่งประโยค ส่วน “วิธีเล่น” และ “ตั้งค่า” เป็นปุ่มรอง หน้าแรกยังไม่แสดงรายวิชา สถิติ รางวัล หรือแผนที่ทั้งหมด ข้อนี้เป็นข้อเสนอของงานนี้ ไม่ใช่ผลการตรวจเมนูเปิดเกมของเกมอ้างอิง
2. **หลังเริ่มจึงแสดง “เลือกวิชา”** ใช้ปุ่มแถวหรือป้ายสมุดที่มีชื่อวิชา ไอคอน และคำอธิบายหนึ่งบรรทัด เช่น “คณิตศาสตร์ — ฝึกคิดผ่านการต่อสู้” เลือกแล้วแสดงสถานะชัด พร้อมปุ่ม “ออกเดินทาง” หนึ่งปุ่ม มี “ย้อนกลับ” ที่คงการเลือกเดิม
3. **กางแผนที่เป็นเหตุและผลของการเลือก** ป้ายวิชาจางลง → แผนที่พับอยู่เลื่อนมาวาง → สองปีกกางออกพร้อมเงารอยพับ → เส้นทางและจุดหมายปรากฏ → จุดเริ่มต้นสว่างขึ้น ไม่ใส่ข้อความสำคัญบนปีกที่ยังหมุนอยู่
4. **ตั้งเป้าทรานซิชันประมาณ 0.8–1.2 วินาที และข้ามได้** เป็นค่าตั้งต้นเพื่อทดสอบ ไม่ใช่เวลาจากเกมอ้างอิง การกด Space/Enter หรือปุ่ม “ข้าม” ควรเปิดแผนที่จนจบทันที เมื่อเปิด reduced motion ให้แสดงแผนที่สำเร็จรูปหรือ fade สั้น ๆ และอย่าใช้อนิเมชันวนที่บังการอ่าน
5. **ให้แผนที่บอกการกระทำถัดไป** หัวข้อ “เลือกจุดเริ่มต้น” ชื่อวิชาปัจจุบัน คำอธิบายสัญลักษณ์สั้น ๆ และจุดที่กดได้เด่นกว่าจุดอนาคต ใช้ทั้งไอคอน ข้อความ และเส้นขอบในการบอกสถานะ ไม่พึ่งสีอย่างเดียว บนมือถือซูมไปบริเวณเริ่มต้นแทนการย่อข้อความทั้งแผนที่

## เกณฑ์ตรวจงาน

- ผู้เล่นใหม่เห็นวิธีเริ่มทันที และเข้าใจว่าเลือกวิชาก่อนเลือกเส้นทาง
- ย้อนกลับจากเลือกวิชาหรือแผนที่ได้โดยไม่หลง และไม่มีการกดซ้ำเพื่อเริ่มรอบซ้อน
- อนิเมชันจบแล้วโฟกัสคีย์บอร์ดไปยังหัวข้อหรือจุดเริ่มต้น; การข้ามให้ผลเหมือนปล่อยเล่นจนจบ
- ทดสอบการอ่านชื่อวิชาและปุ่มที่ความกว้าง 360px, การใช้คีย์บอร์ด และ reduced motion
- ประเมินกับผู้เรียนจริงภายหลัง: จำนวนคลิกผิดและเวลาหาจุดเริ่มต้นเป็นหลักฐานว่าการเปลี่ยนแปลงช่วยได้ ไม่อนุมานประสิทธิผลด้านการเรียนจากความนิยมของเกมอ้างอิง
