# Unit Hunter — สเปกต้นแบบเกมให้ความรู้

วันที่: 23 ตุลาคม 2026

สถานะ: รวบรวมข้อที่ตกลงในบทสนทนาเพื่อยืนยันภาพรวมก่อนพัฒนา ยังไม่ได้แก้ระบบเกม

## เป้าหมายและขอบเขต

เกม roguelike แบบผลัดตา ไม่มีการ์ด สำหรับผู้เรียนระดับ ม.ต้น ฝึกแปลงหน่วยความยาว มวล และเวลา เลือกหนึ่งหัวข้อก่อนเริ่มรอบ ใช้หัวข้อนั้นตลอดแมพ แยกอันดับตามหัวข้อ

เริ่มจากโหมดมีจุดจบหนึ่งเขต เป้าหมายเวลาเล่นประมาณ 10–15 นาที จำนวนห้องและความยาวการต่อสู้ต้องปรับจากการทดลองจริง เพิ่ม Endless ในระยะถัดไป

## วงจรต่อสู้ที่ตกลงแล้ว

ตาผู้เล่น: แสดงท่าที่ศัตรูเตรียมใช้ → เลือกสกิล → ตอบคำถาม → ถ้าถูกเข้า QTE → คำนวณผลสกิล → ตรวจจบการต่อสู้ → ตาศัตรู

ตาศัตรู: แสดงการโจมตี → ตอบคำถามเพื่อป้องกันทันที → ถ้าถูกเข้า QTE → คำนวณความเสียหาย → ตรวจแพ้ → กลับตาผู้เล่น

ตาศัตรูยังไม่มีการเลือกท่าป้องกันเพิ่มเติม ศัตรูที่ตายแล้วไม่โจมตีต่อ

| ผลลัพธ์ | ดาเมจที่ผู้เล่นทำ | ดาเมจที่ผู้เล่นได้รับ |
| --- | ---: | ---: |
| Perfect | 120% | 75% |
| Good | 100% | 100% |
| Bad | 75% | 115% |

- ตอบผิดเป็น Bad ทันที ข้าม QTE
- ตอบถูกเข้า QTE ทุกตา จังหวะแม่นได้ Perfect ใกล้เคียงได้ Good พลาดหนักหรือไม่ทันได้ Bad
- ตอบถูกแต่ QTE พลาดได้รับผล Bad เช่นเดียวกับตอบผิด แต่สถิติความถูกต้องของคำตอบยังนับว่าตอบถูก
- ตารางนี้แทนข้อเสนอเดิมเรื่องตอบถูกลดดาเมจ 50% หรือ QTE เฉพาะท่าพิเศษ
- ระยะเวลา QTE และความกว้างแต่ละโซนเป็นค่าทดลอง ต้องตรวจทั้งคีย์บอร์ดและการแตะ

## คำถามและการเรียน

- เลือกตอบ 4 ตัวเลือก มีคำตอบถูกเพียงข้อเดียว ตัวลวงอิงความเข้าใจผิด เช่น คูณแทนหาร
- ไม่จับเวลาบังคับตอบในโหมดปกติ และคิดเลือกสกิลได้โดยไม่มีเวลาจำกัด
- ตอบผิดแสดงคำตอบและวิธีคิดอย่างน้อย 3 วินาที แล้วให้ผู้เล่นกดไปต่อเอง
- นำแนวคิดที่ตอบผิดกลับมาฝึกด้วยโจทย์ใหม่ โดยไม่วนรับรางวัลจากเหตุการณ์เดิม
- โจทย์อยู่ในระดับที่เลือก เส้นทางอีลิตเพิ่มความท้าทายของการต่อสู้ ไม่เพิ่มเนื้อหาข้ามพื้นฐาน

## สกิลและการสร้างบิลด์

- ติดตั้งสกิลพิเศษได้ 4 ช่อง มีโจมตีพื้นฐานใช้ฟรีแยกต่างหากให้ใช้ได้เสมอ
- สกิลพิเศษใช้คูลดาวน์นับตามตาผู้เล่น ยังไม่มีระบบมานา
- รางวัลหลังชนะให้เลือก 1 จาก 3 หรือข้าม: สกิลใหม่ อัปเกรดสกิล หรือไอเทมติดตัว
- หากช่องเต็ม การรับสกิลใหม่ต้องเลือกสกิลที่จะทดแทนก่อนยืนยัน
- ไอเทมเน้นปฏิสัมพันธ์กับสกิล เช่น Perfect ลดคูลดาวน์ ไม่เพิ่มแต่ดาเมจ
- รายชื่อสกิล ดาเมจ คูลดาวน์ และผลของสกิลที่ไม่ใช่โจมตีเป็นงานออกแบบรายละเอียดก่อนเชื่อมระบบ ไม่ถือว่าตารางดาเมจใช้กับการรักษาหรือบัฟโดยอัตโนมัติ

## แมพและเหตุการณ์

ใช้แมพแตกแขนงที่มีห้องต่อสู้ อีลิต เหตุการณ์ ร้านค้า สมบัติ จุดพัก และบอส ผู้เล่นมองเห็นประเภทห้องและเส้นเชื่อมล่วงหน้า เลือกได้เฉพาะทางที่เชื่อมและเดินหน้าอย่างเดียว

ข้อเสนอจำนวนชั้น น้ำหนักสุ่ม ตัวอย่างเหตุการณ์ และข้อจำกัดกราฟอยู่ใน `roguelike-map-plan.md` เป็นค่าต้นแบบที่ปรับได้ ไม่ใช่กฎที่ถอดจากเกมอื่น

## จบรอบ บันทึก และอันดับ

- แพ้แล้วเริ่มแมพใหม่ สูญเสียบิลด์ของรอบ แต่เก็บประวัติการเรียนและหัวข้อที่ควรทบทวน
- เล่นทั่วไปสุ่มแมพ บันทึกและกลับมาเล่นต่อได้
- รอบจัดอันดับรายวันใช้ seed และระดับโจทย์เดียวกันภายในหัวข้อเดียวกัน รวมชุดเริ่มต้นและเวอร์ชันกติกาเดียวกัน
- โหมดมีจุดจบแสดงเวลาจบและความแม่นยำ จัดอันดับเวลาเฉพาะรอบที่ชนะ
- เวลารอบจัดอันดับรวมการอ่านโจทย์ เลือกเส้นทาง และดูเฉลย หากออกจากรอบกลับมาเล่นได้แต่ไม่ส่งอันดับ
- ต้นแบบเก็บอันดับในเครื่อง ยังไม่ใช่อันดับออนไลน์ที่ตรวจสอบผลแล้ว
- ระยะถัดไปเพิ่มอันดับห้องเรียนด้วยรหัสห้องและชื่อเล่น พร้อมเซิร์ฟเวอร์ตรวจผล
- Endless แยกอันดับด้วยคะแนนจากความถูกต้องและความคืบหน้า สูตรคะแนนต้องออกแบบเมื่อเริ่มโหมดนี้ ไม่ให้การยื้อสู้เพิ่มคะแนนได้ไม่จำกัด

## ลำดับลงมือที่เสนอ

1. ทำการต่อสู้หนึ่งห้องให้ครบวงจร เลือกสกิล → คำถาม → QTE → ศัตรูโจมตี → ป้องกัน → ชนะหรือแพ้
2. เพิ่มชุดสกิลต้นแบบและรางวัล เพื่อพิสูจน์ว่าการเลือกสกิลมีความหมาย
3. สร้างแมพแตกแขนงและสถานะห้อง พร้อมเหตุการณ์ ร้านค้า สมบัติ จุดพัก และบอส
4. เชื่อมการบันทึก ประวัติการเรียน หน้าจบเกม และอันดับในเครื่อง
5. ทดลองทั้งรอบ ปรับจำนวนคำถาม ความยาว QTE ความเสียหาย และเวลาจบรอบ

## เกณฑ์ตรวจต้นแบบ

- ตอบผิดและ QTE พลาดใช้ตัวคูณถูกฝั่ง ไม่คูณ Bad ซ้ำสองครั้ง
- ไม่มีการเดินตาซ้ำ รับรางวัลซ้ำ หรือศัตรูโจมตีหลังตาย
- คูลดาวน์ไม่ทำให้ผู้เล่นไม่มีท่าให้ใช้ และโหลดกลับมาไม่รีเซ็ตเพื่อเอาเปรียบ
- แมพไม่มีทางตัน ทุกห้องที่เลือกได้มีทางถึงบอส และไม่บังคับผ่านอีลิต
- โหลดแล้วรักษาแมพ ผลรางวัล สถานะห้อง และผลคำถาม/QTE ที่ตัดสินแล้ว
- คำตอบที่เทียบเท่ากันไม่ปรากฏเป็นหลายตัวเลือกถูก และคำอธิบายตรงกับโจทย์
- บันทึกความถูกต้องของคำตอบแยกจากผล QTE

## ประเด็นตรวจจากการทดลอง

ดาเมจ 75% เมื่อตอบผิดอาจทำให้กดเดายังผ่านได้ง่าย ต้องวัดอัตรารอดและเวลาเล่นจริง คงตัวคูณตามที่ผู้ใช้กำหนดก่อน การเปลี่ยนกฎหลักต้องกลับมาตกลง ส่วนค่าดาเมจพื้นฐาน HP และคูลดาวน์ปรับเพื่อทดลองได้
